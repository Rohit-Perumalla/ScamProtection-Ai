# 🛡️ ScamProtAI

### AI-Based Scam & Phishing Detection System

ScamProtAI is an AI-powered cybersecurity web application designed to help users identify potential **scam and phishing messages** and suspicious online content.

The system analyzes user-provided content and provides an easy-to-understand risk classification to improve cybersecurity awareness and help users make safer decisions online.

---

## 🚀 Live Demo

🌐 **Website:** https://scam-protection-ai-nine.vercel.app/

---

## 🎯 Problem Statement

Online scams and phishing attacks are becoming increasingly common through:

- 📱 SMS messages
- 📧 Emails
- 🔗 Suspicious URLs
- 💬 Social media messages
- 💰 Fake offers and prize messages
- 🔐 Fake account verification requests

Many users cannot easily identify whether a message or link is legitimate or malicious.

ScamProtAI aims to provide a simple AI-based solution that helps users recognize suspicious content.

---

## 💡 Our Solution

ScamProtAI uses AI/ML techniques to analyze suspicious content and provide:

- 🟢 **Safe**
- 🟡 **Suspicious**
- 🔴 **Likely Scam**

The system also provides a **risk score**, detected indicators, an explanation of the result, and recommended safety actions.

---

## ✨ Key Features

### 🛡️ AI Scam Detection
Analyze suspicious messages and identify potential scam or phishing patterns.

### 🔗 URL Analysis
Analyze URLs for suspicious characteristics and potential phishing indicators.

### 📊 Risk Score
Generate a risk score to help users understand the severity of the detected threat.

### 🔍 Explainable Results
Instead of only displaying a prediction, ScamProtAI explains the suspicious indicators detected in the input.

### 💡 Safety Recommendations
Provides practical recommendations to help users avoid scams.

### 📱 Responsive Web Interface
The application is designed to work across desktop, tablet and mobile devices.
